# INKdown 🪶

**Write, paste, ink and organise: one notebook app that feels native on your phone, tablet and desktop.**

INKdown combines a rich text and Markdown editor with natural handwriting tools, so typed notes, AI answers, diagrams and pen sketches can all live on the same page.

---

## Main Features

### 1. Rich Text Editor with Markdown

- **Markdown text boxes**: type Markdown and see it rendered as clean, formatted text: headings, bold, italic, lists, tables, code blocks and quotes.
- **Math equations**: write formulas with LaTeX syntax; they render beautifully using KaTeX.
- **Place text anywhere**: add a text box on any part of a page, then move, resize and rotate it freely.
- **Live editing**: tap a text box to edit it; formatting stays visible as you type.

### 2. Paste AI Responses Without Losing Formatting

Copy an answer from ChatGPT, Claude, Gemini or any other AI chat, paste it into INKdown, and the structure comes with it.

- Headings, bullet and numbered lists, tables, bold and italic text, inline code and code blocks are preserved.
- Math and equations stay readable.
- No more cleaning up flattened plain text after every paste.
- Paste from websites and documents works the same way.

### 3. Inking: Handwriting and Drawing

Write and draw directly on the page with a stylus, finger or mouse.

| Tool | What it does |
|---|---|
| **Pen** | Smooth everyday handwriting, with several pen types to choose from |
| **Ink pen** | Fluid, natural ink strokes |
| **Calligraphy pen** | Expressive strokes with varying width |
| **Highlighter** | Semi-transparent marker for emphasising text and diagrams |
| **Eraser** | Removes strokes you touch |
| **Area eraser** | Wipes out everything inside the area you brush over |
| **Lasso** | Select ink, text and images, then move, copy, cut or delete them |
| **Laser pointer** | A red trail that fades away, ideal for presenting |
| **Smart ink** | Assisted ink tools for tidier drawings |

- Adjustable **thickness** with quick presets.
- Full **colour palette** with saved colours.
- **Pressure-sensitive** strokes when using a stylus.
- Fingers scroll and pinch-zoom while the stylus draws, so you never draw by accident.
- Unlimited **undo and redo**.

### 4. Shapes and Diagrams

Draw clean shapes in one gesture: line, arrow, rectangle, rounded rectangle, ellipse, triangle, right triangle, diamond, pentagon, hexagon, star and heart.

### 5. Images

Insert pictures into any page, then resize, move and rotate them. Combine them with handwriting and typed notes.

### 6. PDF Import and Export

- **Import PDFs** and write or annotate directly on top of every page.
- **Export to PDF** with vector quality, so your ink and text stay sharp at any zoom.
- Exported files are optimised to keep the size small.

---

## Notebooks and Library

- A **Library** screen shows all your notebooks as covers on a shelf.
- Each notebook holds multiple **sections**, and each section holds multiple **pages**.
- Choose from a gallery of **notebook covers** (nature, subjects and plain colours) when creating a notebook or later via *Change cover*.
- **Search** across notebook and section names, and sort by last edited, name or size.
- **Recent** view for what you worked on this week.
- Press and hold a notebook to jump straight into one of its sections.
- A **page list** lets you move quickly around long notebooks.

## Backup and Storage

- Your notes are **stored on your device**, with autosave.
- **Download a backup** of any notebook and restore it later.
- **Cloud backup** with clear status badges: backed up, out of date, or not backed up.
- A **storage metre** shows how much space you are using.

## A Native-App Feel

- Designed for **phones, tablets and desktop**, with safe-area support and a full-screen app mode.
- **Glass-style toolbar** that adapts to light and dark pages.
- **Bottom-sheet menus** on phones, popovers on larger screens.
- Smooth, spring-style animations: cards rise in, covers respond to touch, and notebooks zoom open.
- Pinch to **zoom from 25% to 400%**.
- Respects the system **reduced-motion** setting.

---

## Quick Start

1. Open INKdown and tap **New notebook**. Choose a name and a cover.
2. Add a **text box** and type or paste your content, including AI responses.
3. Switch to the **pen** or **highlighter** and mark up your page.
4. Import a **PDF** to annotate it, or add **images** and **shapes**.
5. Export to **PDF** or back up your notebook when you are done.
